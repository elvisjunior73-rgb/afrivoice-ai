# Contribuer à AfriVoice AI

Merci de votre intérêt pour le projet AfriVoice AI ! Nous sommes ravis de vous accueillir dans notre communauté.

## Comment Contribuer

Il existe plusieurs façons de contribuer à ce projet :

### 1. Annotation de Données (Label Studio)
L'annotation humaine est cruciale pour améliorer la qualité de nos modèles.
- **Où ?** Sur notre instance Label Studio (lien à venir).
- **Quoi ?** Écouter des segments audio et corriger les transcriptions automatiques.
- **Comment ?** Suivez le guide d'annotation détaillé (disponible dans `docs/guide_annotation.md`).

### 2. Collecte de Données
Aidez-nous à trouver de nouvelles sources audio en Lingala, Kikongo et Sango.
- **Sources acceptées :** Vidéos YouTube, TikTok, flux radio, podcasts, etc.
- **Comment ?** Ouvrez une Issue avec le lien vers la source et la langue correspondante.

### 3. Développement de Code
Vous pouvez améliorer nos scripts Python, notre pipeline CI/CD ou nos notebooks Colab.
- **Langages :** Python, Bash, YAML (GitHub Actions).
- **Processus :**
  1. Forkez le dépôt.
  2. Créez une branche pour votre fonctionnalité (`git checkout -b feature/ma-fonctionnalite`).
  3. Commitez vos changements (`git commit -m 'Ajout de ma fonctionnalité'`).
  4. Poussez vers la branche (`git push origin feature/ma-fonctionnalite`).
  5. Ouvrez une Pull Request.

## Conventions de Code
- **Langue :** Tous les commentaires et la documentation doivent être en français.
- **Style :** Suivez les conventions PEP 8 pour le code Python.
- **Autonomie :** Chaque script doit rester autonome et exécutable sur Google Colab.

## Signaler un Bug
Si vous trouvez un bug, veuillez ouvrir une Issue en décrivant :
- Le comportement attendu.
- Le comportement observé.
- Les étapes pour reproduire le bug.
- Votre environnement (OS, version de Python, etc.).

Merci pour votre contribution !
